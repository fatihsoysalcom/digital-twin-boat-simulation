# Digital Twin Boat Simulation

This example demonstrates the core concept of a "digital twin" by simulating a boat. It uses a Python class to represent the digital twin, which is continuously updated with simulated sensor data like fuel level, engine RPM, speed, and location. The simulation shows how the digital twin reflects the real-time state of its physical counterpart.

## Language

`python`

## How to Run

Save the code as `main.py`.
Run from your terminal: `python main.py`
